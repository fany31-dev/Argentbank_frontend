# Projet Argent Bank – Projet 10 OpenClassrooms

Implémentez le front-end d'une application bancaire avec React
**********************************************************************************

## Contexte du projet

Dans ce projet, j'ai travaillé sur le développement front-end d’une application bancaire en utilisant React et Redux pour créer une expérience utilisateur dynamique et réactive.

Ma mission principale était d'intégrer le front-end avec le back-end via des appels API : appels à l'API REST pour connecter les deux parties de l'application, assurant une communication fluide entre le client et le serveur.

**********************************************************************************
**********************************************************************************

### Compétences validées

• Afficher les données du back end sur l'interface via des appels API
• Configurer des routes API pour la communication client / serveur
• Implémenter la gestion des données avec Redux pour assurer le fonctionnement du front
• Utilisation de Redux pour gérer les données de l'application pour maintenir un état global cohérent à travers l'application.

### Outils et Technologies utilisées

• VS CODE
• REACT 19
• REACT ROUTER 7
• VITE 8
• REDUX
• SWAGGER
• GITHUB
• Aucune librairie REACT externe utilisée
Note : Ce projet utilise les versions REACT, REACT ROUTER, VITE et REDUX fournies par le template initial.

#### Fonctionnalités principales

Page /Home

Page /Login

Page /Profile

Page /Error
• Message d’erreur 404
• Lien de retour vers l’accueil

Navigation
• Header + Footer
• Routes gérées avec REACT ROUTER
